# 🌾 AgriTwin AI

### India's Intelligent Farm Operating System

> From Prediction to Action — Everything a Farmer Needs in One Platform.

AgriTwin AI is an AI-powered smart farming platform that helps farmers make better and data-driven decisions.

## ✨ Key Features

- 🤖 AI Crop Disease Detection
- 🌦️ Weather Intelligence
- 📈 AI Yield Prediction
- 🌾 Digital Farm Twin
- 💰 Financial Dashboard
- 📊 Mandi Price Insights
- 🛒 Smart Marketplace
- 🧰 Farm Service Hub
- 🧮 AI Selling Guide

## 🛠️ Tech Stack

- HTML, CSS, JavaScript
- Node.js & Express.js
- MongoDB Atlas
- AI & Weather APIs
- JWT Authentication
- Vercel & Render

## 🎯 Our Goal

To provide farmers with one intelligent platform for crop monitoring, farm management, market decisions, financial tracking, and agricultural services.
